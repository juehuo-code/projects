# 算法过程可视化系统

## 系统简介

算法过程可视化系统是一个面向算法教学的交互式可视化平台，集成**快速排序**、**汉诺塔**、**哈夫曼树构造**和 **Dijkstra 最短路径**四类经典算法，通过图形化、动画化的方式动态展示算法的每一步执行过程，帮助用户直观理解算法的运行逻辑。

## 系统运行方式

### 方式一：直接打开（推荐）

1. 用浏览器（Chrome、Edge、Firefox 均可）直接打开 `index.html` 文件
2. 无需安装任何依赖，无需联网

### 方式二：本地服务器

```bash
# 在项目目录下执行
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 操作指南

### 1. 选择算法

点击顶部标签页选择要观察的算法：
- **快速排序**（基础）— 分治排序算法
- **汉诺塔**（基础）— 递归分治经典问题
- **哈夫曼树**（中等）— 贪心算法构造最优二叉树
- **Dijkstra 最短路径**（中等偏上）— 图论单源最短路径

### 2. 设置参数

支持三种参数设置方式：
- **手动输入**：在左侧参数面板中直接填写算法参数
- **随机生成**：点击"随机生成"按钮，系统自动生成合法参数
- **测试用例**：从下拉列表中选择预设测试用例

### 3. 运行控制

| 按钮 | 功能 |
|------|------|
| **开始** | 自动播放模式，按800毫秒间隔逐步执行 |
| **暂停** | 暂停自动播放，保持当前步骤展示 |
| **继续** | 从暂停状态恢复自动播放 |
| **单步执行** | 每点击一次执行一个步骤 |
| **回退** | 回退到上一步（暂停或完成后可用） |
| **重置** | 清空执行状态，重新设置参数 |

### 4. 查看结果

- **可视化画布**：动态展示算法每一步的数据结构状态
- **步骤说明**：底部信息栏显示当前步骤的文字描述
- **最终结果**：算法执行完毕后展示最终结果和统计信息
- **复杂度信息**：左侧面板显示时间复杂度和空间复杂度

## 参数格式说明

### 快速排序
- **arr**：待排序数组，元素以英文逗号分隔，如 `42,15,73,28,61,39,84,55`
- 元素个数 2~100，元素值 -999~999

### 汉诺塔
- **n**：圆盘数量，整数，范围 1~10

### 哈夫曼树
- **chars**：字符序列，如 `ABCDE`
- **weights**：对应权值，以英文逗号分隔，如 `5,2,8,3,7`
- 字符数量 2~26，权值 1~99

### Dijkstra 最短路径
- **vertex_count**：顶点数量，整数，范围 2~20
- **edges**：边列表，格式 `起点,终点,权重;起点,终点,权重`，如 `0,1,4;0,2,2;1,3,10`
- **start_vertex**：起始顶点编号，从 0 开始

## 测试用例

系统为每种算法预设了多个测试用例，覆盖常规输入和边界情况：

| 算法 | 用例数 | 覆盖类型 |
|------|--------|----------|
| 快速排序 | 4 | 随机数组、逆序数组、已有序数组、含重复元素 |
| 汉诺塔 | 4 | n=1, n=3, n=4, n=6 |
| 哈夫曼树 | 4 | 标准示例、2字符、等权值、6字符 |
| Dijkstra | 4 | 稀疏图、稠密图、单边图、不同起点 |

共计 **16** 个测试用例（超过要求的 8 个）。
