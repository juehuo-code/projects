# 红脉智联 — 红色文化传承平台 技术详解文档

> 适用场景：毕业设计 / 项目答辩
> 项目定位：以数字化手段传承红色文化，面向青年群体的红色教育综合平台

---

## 一、项目技术架构总览

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | Vue 3（组合式 API） | 主流渐进式框架，组件化开发 |
| 构建工具 | Vite 8 | 新一代前端构建工具，开发启动快、热更新快 |
| 状态管理 | Pinia 3 | Vue 3 官方推荐的状态管理库 |
| 路由 | Vue Router 4 | SPA 单页应用路由，HTML5 History 模式 |
| CSS 方案 | Tailwind CSS 3 + 自定义 CSS | 原子化 CSS 框架 + 红色主题定制 |
| HTTP 客户端 | Axios | 统一的 API 请求封装，拦截器处理 Token |
| 可视化图表 | ECharts 6 | 管理后台数据大屏图表 |
| 地图 | 高德地图 (AMap) | 红迹地图展示先烈足迹路线 |
| PDF 生成 | jsPDF + html2canvas | 志愿证书 PDF 导出 |
| 轮播 | Swiper 12 | 照片画廊轮播组件 |
| 后端语言 | PHP（无框架，原生） | 轻量级 RESTful API |
| 数据库 | MySQL | 关系型数据库，utf8mb4 编码 |
| AI 接入 | 豆包大模型（火山引擎） | 通过 Responses API 提供 SSE 流式对话 |
| 部署环境 | 宝塔面板 (Linux) | Nginx + PHP + MySQL 一键部署 |

## 三、配置文件详解

### 1. 后端全局配置 `api/config.php`（★ 核心配置文件）

这是整个后端唯一需要修改的配置文件，被所有 PHP API 文件引入：

| 配置项 | 说明 | 当前值（示例） |
|--------|------|---------------|
| `$DB_HOST` | MySQL 数据库地址 | `127.0.0.1` |
| `$DB_NAME` | 数据库名 | `red-pulse` |
| `$DB_USER` | 数据库用户名 | `red-pulse` |
| `$DB_PASS` | 数据库密码 | `red-pulse` |
| `$DB_PORT` | 数据库端口 | `3306` |
| `$SECRET` | Token 签名密钥 | `YOUR_TOKEN_SECRET` |
| `$AI_KEY` | 豆包 AI API Key | （火山引擎 ARK API Key） |
| `$AI_URL` | AI 接口地址 | `https://ark.cn-beijing.volces.com/api/v3/responses` |
| `$AI_MODEL` | AI 模型名称 | `doubao-seed-1-8-251228` |

此外还包含以下全局工具函数：
- `ok($data, $msg)` — 返回成功 JSON 响应
- `fail($msg, $code)` — 返回错误 JSON 响应
- `input()` — 读取 JSON 请求体
- `checkLogin()` — 验证 Token 并返回当前用户
- `makeToken($uid)` — 生成 Token（格式：`uid.timestamp.md5`）
- `addBeans($userId, $amount, $reason)` — 增加传承豆并记录流水

> **部署时只需修改 config.php 中的数据库信息和 AI Key，其他文件无需改动。**

### 2. 前端 Vite 配置 `frontend/vite.config.js`

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 开发端口 | `3000` | 前端开发服务器端口 |
| API 代理 | `/api` → `http://localhost:80` | 开发时将 API 请求转发到 PHP 后端 |
| 路径别名 | `@` → `src/` | 导入时可写 `@/components/...` |
| 输出目录 | `dist` | 构建产物输出目录 |

### 3. Tailwind 主题配置 `frontend/tailwind.config.js`

- **主色调**：`primary` 系列（红色系，从 `#fef2f2` 到 `#450a0a`），符合红色文化主题
- **字体**：`kai`（楷体）、`song`（宋体），体现中国传统文化气息

### 4. 前端入口 `frontend/index.html`

- 页面标题："红脉智联 - 红色文化传承平台"
- 引入高德地图 JS API（安全密钥配置）
- `<div id="app">` 为 Vue 挂载点

### 核心调用链路举例

**① 用户登录流程**：
`Login.vue` → `api/user.js` 的 `login()` → `POST /api/auth.php?action=login` → `config.php` PDO连接 MySQL → 验证密码 → 返回 Token → 存入 localStorage + Pinia store

**② 红迹地图展示**：
`MapView.vue` → `api/martyr.js` 的 `getMartyrs()` → `GET /api/martyrs.php` → MySQL 查询 → 返回英烈经纬度+路线 → 高德地图渲染标记点

**③ AI 聊天**：
`AiChat.vue` → `api/ai.js` 的 `chatStream()` → `POST /api/ai.php`（SSE流）→ PHP cURL 转发火山引擎 → 流式返回文本 → 前端逐字展示

**④ 传承商城购买**：
`ShopModal.vue` → `api/shop.js` 的 `buyItem()` → `POST /api/shop.php?action=buy` → 事务操作（扣豆 + 入库 + 记账）→ 更新 Pinia store

## 五、核心功能模块详解

### 模块一：红迹地图（前端 + 后端）

**涉及文件**：
- 前端：`views/map/MapView.vue`、`components/HeroCard.vue`、`stores/martyr.js`
- 后端：`martyrs.php`、`letters.php`
- 数据：`photo/` 目录下 37 位英烈照片

**功能说明**：
- 首页展示 37 位英烈卡片网格
- 点击进入高德地图，地图上标记每位英烈的生平轨迹点
- 支持查看英烈生平时间轴、路线图
- 点击可进入英烈家书阅读，支持用户"回信"互动

**技术要点**：
- 使用高德地图 JSAPI Loader 按需加载
- 英烈路线以坐标数组存储，地图上绘制 polyline 连线
- Pinia store 包含本地 Mock 数据，后端不可用时自动降级

---

### 模块二：红色知识大闯关（前端 + 后端）

**涉及文件**：
- 前端：`views/game/GameHub.vue`、`views/game/QuizEndless.vue`、`views/game/MemoryMatch.vue`、`views/game/ChoiceMoment.vue`
- 后端：`quiz.php`、`choice.php`

**三种游戏模式**：

| 游戏 | 说明 | 技术特点 |
|------|------|----------|
| 百题斩 | 无限答题，答错结束 | 随机出题、排除已答、后端校验答案防作弊 |
| 翻翻乐 | 记忆翻牌配对 | 纯前端实现，英烈卡片配对 |
| 抉择时刻 | 历史剧情选择 | 31 位英烈专属剧情，每关 2 步选择，答错需写反思 |

**抉择时刻的设计特色**（答辩亮点）：
- 为 37 位英烈每位编写了专属的抉择剧情关卡
- 每关通过"场景化叙事 + 三选一"让用户代入英烈处境
- 错误选项仅涉及胆怯、犹豫等个人层面，**不涉及叛变投敌**
- 答错时要求用户写不少于 4 个字的反思，再展示真实历史结局
- 实现了"沉浸式红色教育"，而非简单的知识问答

### 模块三：志愿者接单平台（前端 + 后端）

**涉及文件**：
- 前端：`views/volunteer/TaskList.vue`、`views/volunteer/TaskDetail.vue`
- 后端：`projects.php`、`submissions.php`、`feedback.php`

**功能说明**：
- 管理员发布志愿项目（照片修复、老兵采访、文物保护、资料整理等类别）
- 志愿者查看并接单，提交作品和志愿心得
- 管理员审核（通过/驳回），通过后自动生成证书编号
- 审核通过奖励传承豆

### 模块四：传承商城与装扮系统（前端 + 后端）

**涉及文件**：
- 前端：`views/shop/DressUpPage.vue`、`components/ShopModal.vue`、`components/DressUpModal.vue`、`components/Mascot.vue`、`stores/shop.js`
- 后端：`shop.php`

**经济系统设计**：

| 要素 | 说明 |
|------|------|
| 货币 | "传承豆"（虚拟积分） |
| 获取途径 | 注册奖励(50)、答题正确(2)、家书回信(20)、抉择通关(10)、翻翻乐通关(15)、志愿完成(30)、勋章点亮(50) |
| 消费途径 | 购买装扮（红星套装、红领巾等6种）、购买游戏道具（提示卡、免错卡、翻倍卡） |
| 装扮系统 | 头部/身体/配饰三个部位，支持预览和保存 |

**技术要点**：
- 商城购买使用数据库事务保证原子性（扣豆 + 入库同时成功或同时回滚）
- 装扮状态存储在 localStorage，页面刷新不丢失
- 传承豆变更记录在 `bean_transactions` 表中，可追溯

### 模块五：红色精神成长馆 — 思政辩论小广场 + 解忧站（前端本地闭环）

**涉及文件**：
- 前端：`stores/ideology.js`、`views/ideology/IdeologyHall.vue`、`views/ideology/DebateSquare.vue`、`views/ideology/ReliefStation.vue`、`views/ideology/GrowthPoints.vue`
- 管理端：`views/admin/IdeologyDebateManage.vue`、`views/admin/ReliefCommentManage.vue`

**设计亮点**（答辩重点）：

此模块采用 **localStorage 本地闭环架构**，展示了一个完整的"AI + 人工审核"内容社区系统：

1. **思政辩论小广场**：
   - 管理员发布议题（正反方立论），设定 3-7 天辩论周期
   - 用户选择正方/反方发表 200-500 字发言
   - 内置敏感词过滤（AI 模拟审核）：包含违规词 → 直接驳回；字数不足 → 提示补充
   - 管理员人工审核（批准/驳回/标记优质），批准 +5 分，优质 +15 分
   - 支持点赞、评论、收藏互动（每日互动积分上限 10 分）
   - 辩论结束后可提交思政小结（120-600 字，+10 分）
   - 专家顾问可发布总结点评

2. **红色精神解忧站**：
   - 用户选择困惑类型（学业/就业/人际/奋斗倦怠/理想/社会认知）提交 80-800 字困惑
   - 每位英烈精神对应一种困惑类型的解忧方案模板
   - 管理员审核后发布，附带"红色精神解码"（对应英烈 + 品质 + 行动建议）
   - 其他用户可评论、点赞、提交感悟、立下成长誓言

3. **成长积分体系**：
   - 5 个等级：初心学徒(0分) → 笃行少年(200分) → 先锋志士(450分) → 精神传承者(750分) → 时代新青年(1100分)
   - 积分来源：辩论发言、解忧感悟、实践记录、互动点赞、成长档案完善
   - 每个等级解锁不同精神权益（电子证书、研学资格、荣誉勋章等）

> **为什么用 localStorage 而非后端存储？**
> 此模块展示了完整的思政互动社区逻辑（发言/审核/点赞/积分/等级），但因涉及 AI 审核 + 人工审核的双重工作流，出于演示目的将数据持久化在浏览器本地。实际部署时只需要将 `ideology.js` 中的 `localStorage` 操作替换为数据库 API 调用即可无缝切换。

### 模块六：AI 智能助手（前端 + 后端 + 火山引擎）

**涉及文件**：
- 前端：`views/ai/AiChat.vue`、`api/ai.js`

**技术实现**：

- 系统提示词限定 AI 为"红色文化小助手"，擅长解读红色历史、烈士事迹
- 配置 `CURLOPT_SSL_VERIFYPEER = false` 解决宝塔服务器 SSL 证书问题

**两个 AI 接口的区别**：
| 接口 | 是否需要登录 | 用途 |
|------|-------------|------|
| `ai.php` | 需要 | 完整对话，支持历史消息，正式聊天 |
| `doubao.php` | 不需要 | 简易单轮问答，游客体验 |

## 七、安全设计

| 措施 | 实现位置 |
|------|----------|
| 密码加密 | `auth.php` 使用 `password_hash($pwd, PASSWORD_BCRYPT)` |
| Token 认证 | `config.php` 自定义签名 Token（`uid.timestamp.md5(uid.ts.secret)`） |
| CORS 跨域 | `config.php` 设置 `Access-Control-Allow-*` 头 |
| 路由守卫 | `router/index.js` 的 `beforeEach` 验证登录态和管理员角色 |
| 答题防作弊 | `quiz.php` 后端校验答案，不信任前端传来的结果 |
| SQL 注入防护 | 全部使用 PDO 预处理语句（`prepare` + `execute`） |
| XSS 防护 | 后端 `JSON_UNESCAPED_UNICODE` + 前端 Vue 模板自动转义 |
| 文件上传限制 | `upload.php` 限制文件类型 + 大小（10MB） |
| 购买事务 | `shop.php` 使用数据库事务（`beginTransaction` + `commit` + `rollback`） |

## 九、答辩建议

### 评委可能关注的问题 & 回答思路

**Q1：这个项目解决了什么问题？**
> 当前红色文化教育多以课堂讲授、参观纪念馆为主，缺乏数字化、互动化的载体。本项目通过"地图+家书+游戏+AI+思政社区"五位一体，让青年在互动中沉浸式感受红色文化。

**Q2：安全性如何保障？**
> 密码 Bcrypt 加密存储、Token 认证、SQL 预编译防注入、答题和购买均在后端校验（不信任前端数据）、文件上传限制类型和大小。

**Q3：抉择时刻模块的设计理念？**
> 传统红色教育问卷是"考你知道什么"，抉择时刻是"让你成为英雄"。通过场景化叙事+代入式选择，让用户理解英烈在关键时刻的信仰抉择。错误选项只涉及个人层面的犹豫（不设叛变投敌选项），答错需写反思，体现教育的引导性而非惩罚性。

**Q4：AI 在项目中的作用？**
> 三处应用：① AI 红色助手（豆包大模型对话）；② 思政辩论 AI 预审（敏感词自动过滤）；③ 家书 AI 解读（辅助理解历史背景）。AI 是辅助工具，不替代人的判断。

**Q5：思政成长馆为什么用 localStorage？**
> 因为它模拟了一个完整的"发布-审核-互动-积分"社区闭环，包含AI自动审核+管理员人工审核的双重工作流。出于演示目的用本地存储，实际部署替换为数据库调用即可。
